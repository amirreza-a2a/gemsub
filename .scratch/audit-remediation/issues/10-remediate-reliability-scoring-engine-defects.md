# 10: fix(store): remediate reliability scoring engine defects

Type: bugfix
Status: resolved
Blocked by: 09

## Question

How do we resolve post-implementation defects in the Reliability Scoring Engine regarding legacy observation fabrication, ranking latency preservation, config map aliasing, IPv6 bracket handling, parser semantic equivalence verification, target policy override strictness, and persistence buffer invariant validation?

## What to build

Implement a focused remediation ticket for the Reliability Scoring Engine defects identified after review of commit `6d8f4ad`:

1. **P0 — Prohibit Fabricated Observations in Legacy Migration**:
   - V1 migration must migrate strictly the single genuine observation actually recorded.
   - Do NOT synthesize fake `StatusPassed` samples from `PreviouslyPassed`.
   - Do NOT fabricate timestamps (`TestedAt.Add(-time.Minute)`) or HTTP status codes (`200`).
   - Do NOT duplicate inconclusive samples from `ConsecutiveInconclusive`.
   - Preserve LKG servability compatibility conservatively without inventing history.
   - Verified live deployment: no live deployment ran `6d8f4ad` (live `./gemsub_state.json` is unversioned V1). Provide defensive `repairBuggyV2History` pass in `Load()` for any buggy V2 snapshot.

2. **P1 — Latency Ranking After Non-Passed Observations**:
   - Latency used for ranking in `PassingRanked()` must derive exclusively from `StatusPassed` observations.
   - Failed or inconclusive probe durations/timeouts must never overwrite the last valid successful latency.
   - Add `LastPassedLatency` and `HasPassed` to candidate record and history.
   - Candidates without a successful pass sort after all candidates with at least one pass (`math.MaxInt64` / `hasPassed == false`).

3. **P1 — Defensive Copying in `ScoringConfig`**:
   - Add `Clone()` to `ScoringConfig` deep-copying `CategoryWeights`.
   - Defensive-copy input in `NewWithConfig(path, cfg)`.
   - Defensive-copy output in `Store.Config()`.

4. **P1 — IPv6 Canonicalization**:
   - Use `net.JoinHostPort` to preserve standard bracket notation (`[2001:db8::1]:443`, `[2001:db8::1]`).
   - Prevent breaking `net.SplitHostPort` and proxy outbound parsers.

5. **P1 — Semantic Equivalence Parser Compatibility Tests**:
   - Expand `TestCanonicalizeLink_ParserCompatibility` to compare parsed outbound configuration structs (Server, ServerPort, credentials/UUID/Password/Method, Flow, TLS, Reality, Transport) between raw and canonical links.

6. **P1 — Tighten Target Policy Override**:
   - Gate 2 in `isServableRecordLocked` disqualifies only when the latest conclusive observation is `StatusFailed` with `ErrRegionBlocked` or `ErrTargetDenied`.
   - `StatusPassed` or `StatusInconclusive` never triggers the hard override gate.

7. **P1/P2 — Validate BoundedHistory Persistence Invariants**:
   - Implement `BoundedHistory.NormalizeAndValidate(defaultCapacity)` ensuring `Capacity > 0`, `len(Samples) == Capacity`, `0 <= Count <= Capacity`, and `0 <= Start < Capacity`.
   - Normalize malformed or corrupted V2 snapshots on `Load()` and guard `Push()` against panics.

## Acceptance criteria

- [x] Legacy V1 migration preserves only genuine observations; no fabricated samples, timestamps, or status codes.
- [x] Ranking latency strictly preserves last valid `StatusPassed` latency and unproven candidates rank worst.
- [x] `ScoringConfig.CategoryWeights` is defensively copied on store initialization and `Config()` retrieval.
- [x] Canonical links with IPv6 addresses preserve bracket notation and remain parseable by Sing-box/Xray parsers.
- [x] Parser compatibility tests assert semantic equivalence across all parsed outbound config fields.
- [x] Target Policy Override triggers only on `StatusFailed` with target restriction categories.
- [x] Deserialized `BoundedHistory` invariants are validated and normalized without panics.
- [x] All tests pass under race detector.

## Answer

Remediated all identified Reliability Scoring Engine defects across `internal/store`:

1. **Clean Legacy V1 Migration & Buggy V2 Repair (`store.go`)**:
   - In `Load()`, V1 migration now pushes strictly one authentic `ProbeSample` reflecting the single recorded probe result.
   - Eliminated synthetic `StatusPassed` sample creation, fake `TestedAt.Add(-time.Minute)` timestamps, fake HTTP 200 codes, and loop duplication from `ConsecutiveInconclusive`.
   - Preserved legacy LKG servability compatibility conservatively in Gate 4 for migrated records (`rec.History.Count == 1 && rec.Latest.PreviouslyPassed && rec.Latest.ConsecutiveInconclusive <= s.cfg.MaxAbsentCycles`).
   - Verified that no live deployment ran `6d8f4ad` (local `./gemsub_state.json` is legacy V1).
   - Added `repairBuggyV2History` in `Load()` to automatically strip fabricated samples from any V2 state file generated by buggy versions.

2. **Latency Ranking Integrity (`record.go`, `history.go`, `store.go`)**:
   - Added `LastPassedLatency time.Duration` and `HasPassed bool` to `CandidateRecord`.
   - Added `LastPassedLatency()` helper to `BoundedHistory`.
   - Updated `PutWithTransition` to update `LastPassedLatency` and `HasPassed` only on `StatusPassed`. Non-passing probe latencies never overwrite prior successful latency.
   - Updated `PassingRanked()` to prioritize candidates with `hasPassed == true` ahead of unproven candidates, and rank strictly by `LastPassedLatency`.

3. **Defensive Config Copying (`config.go`, `store.go`)**:
   - Added `ScoringConfig.Clone()` providing deep copy of `CategoryWeights`.
   - Applied defensive cloning in `NewWithConfig` and `Store.Config()`.

4. **IPv6 Canonicalization (`canonical.go`)**:
   - Updated `CanonicalizeLink` to use `net.JoinHostPort` when port is present, and format `[hostname]` for bare IPv6 addresses.
   - Added IPv6 tests in `canonical_test.go`.

5. **Deep Semantic Equivalence Parser Compatibility (`canonical_test.go`)**:
   - Expanded `TestCanonicalizeLink_ParserCompatibility` to assert semantic equality of Server, ServerPort, credentials (UUID/Password), Flow, TLS (ServerName, Insecure, ALPN), Reality (PublicKey, ShortID), and Transport (Type, Path, Host) across VLESS, Trojan, VMess, and Shadowsocks share links.

6. **Target Policy Override Gating (`store.go`)**:
   - Restricted Gate 2 in `isServableRecordLocked` to check `sample.Status == StatusFailed && (sample.Category == ErrRegionBlocked || sample.Category == ErrTargetDenied)`.
   - Anomalous combinations (`StatusPassed` or `StatusInconclusive`) do not trigger Gate 2.

7. **BoundedHistory Invariant Validation (`history.go`)**:
   - Implemented `NormalizeAndValidate(defaultCapacity)` in `BoundedHistory`, enforcing buffer capacity, slice length, count clamping, and start index bounds.
   - Guarded `Push()` against capacity/slice mismatches.
   - Added regression test `TestScoring_MalformedV2SnapshotRecovery` verifying safe recovery from corrupted state files.
